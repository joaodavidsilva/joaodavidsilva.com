# João David Silva — Personal Website

An independent engineering publication: writing, research, a public knowledge base, projects and a professional profile, all published from one canonical source.

## Language

### Content

**Article**:
A piece in Writing: an argument, essay or reflection with free structure, published once and changed afterwards only through visible corrections.
_Avoid_: Post, blog post, piece

**Study**:
A piece in Research: the record of one investigation, structured as question, hypothesis, method, observations, findings and limitations, with a status of in progress, concluded or abandoned.
_Avoid_: Paper, experiment, research post

**Correction**:
A dated, visible note on an Article recording what changed after publication and why.
_Avoid_: Edit, update, erratum

**Series**:
An ordered set of Articles on one subject, written over time, each readable on its own; it is ongoing or complete.
_Avoid_: Collection, saga, multi-part post

**Now**:
A short, dated statement of what João is currently working on and investigating.
_Avoid_: Status, bio, current focus

### Knowledge Base

**Concept**:
A Knowledge Base entry that defines one term, heavily cross-referenced to other Concepts.
_Avoid_: Definition page, reference, glossary entry

**Guide**:
A Knowledge Base entry explaining a practice, optionally paired with the skill that lets an agent apply it.
_Avoid_: Tutorial, how-to, skill doc

**Skill**:
An instruction file that teaches an agent a practice; written for agents, kept in the skills repo, and never generated from a Guide.
_Avoid_: Prompt, agent doc

### Publishing

**Markdown twin**:
The Markdown copy of a published page, served at the page's path with `.md`, generated from the same source as the HTML.
_Avoid_: Raw version, agent version, mirror

**Original**:
The English version of a page; the only authoritative version.
_Avoid_: Source page, master, default language

**Translation**:
A version of an original in another language. Portuguese translations are reviewed by João; any other language is an **AI translation** and is labelled as such.
_Avoid_: Localisation, version, copy

**Outdated translation**:
A translation made from an earlier revision of its original.
_Avoid_: Stale page, out-of-sync translation

### Projects

**Project**:
Something João maintains over time, with a current state that evolves (versions, releases, status). One-off builds are told through Articles instead.
_Avoid_: Portfolio item, product, work

**Project page**:
The site's own page about a project: what it is, why it exists and the engineering decisions behind it, linking out to the project's own site, repository or store listings. It may also host the project's legal documents.
_Avoid_: Project site, landing page, portfolio entry

### Professional profile

**Professional record**:
The verified, structured account of João's roles, projects, skills, achievements, publications and contributions; the only source for the CV and the About page.
_Avoid_: Profile data, resume data, career history

**Claim**:
One statement in the professional record, always traceable to a source. A claim only João can confirm is an **attested claim**, and is labelled as such.
_Avoid_: Fact, bullet, achievement line

**CV**:
The document produced from the full verified professional record, offered for download in PDF. There is exactly one; it is never tailored to a job description.
_Avoid_: Standard CV, dynamic CV, tailored CV
