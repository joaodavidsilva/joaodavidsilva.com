# Website repo is the canonical home of the Knowledge Base

Knowledge Base documents are migrated one by one from `joaodavidsilva/skills` into this repo, and once a document has moved the skills repo links to its published page instead of keeping its own copy. We chose this over keeping the skills repo as the source and ingesting it at build time, so that the website is the single canonical publication for all of João's technical content; the cost is a long transition during which some documents still live only in the skills repo.
