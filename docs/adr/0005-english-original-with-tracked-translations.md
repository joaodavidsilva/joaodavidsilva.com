# English original with tracked translations

All content is written in English, which is the original and the only version that is authoritative. Pages may also exist in other languages under a language prefix (`/pt/...`); English stays at the root, and pages are linked with `hreflang`. Portuguese is reviewed by João and carries no label; any other language is labelled "Translated by AI". Each translation records which revision of the original it was made from, so the build can detect drift: an outdated translation shows a notice linking to the original, and an outdated translation of a legal document fails the build. We chose per-page translations over a full i18n system so that a missing translation simply isn't offered, instead of every page being duplicated.

## Consequences

- Every translation has its own Markdown twin; `llms.txt` lists originals and points to the available translations.
