# Engineering *beyond* implementation.

This is the home of João David Silva's writing, research, knowledge base and projects. Everything here is written to be read start to finish, cited, and corrected in public when it turns out to be wrong.

## How I work

Plan comprehensively. Build incrementally. *Evolve continuously.*

1. **Grill before building.** Ask every difficult question before implementation begins.
2. **Write the language down.** Give people and agents the same durable vocabulary.
3. **Spec, then tickets.** Keep every piece of work independently verifiable.
4. **Implement, then look back.** Feed corrections into the next plan.

Open-sourced as [AI Skills](https://github.com/joaodavidsilva/skills).
